Kebijakan Privasi — Puskesdoc Generator

Terakhir diperbarui: 14 Oktober 2026

Puskesdoc Generator adalah aplikasi web untuk membantu Puskesmas menyusun dokumen akreditasi (SOP, SK, KAK, Pedoman, Panduan). Kebijakan ini menjelaskan bagaimana data Anda ditangani.

1. Penyimpanan Data Lokal

Seluruh data yang Anda masukkan (profil faskes, dokumen, variabel, template, pengaturan) tersimpan lokal di browser perangkat Anda (localStorage). Data tidak dikirim ke server kami — aplikasi ini berjalan sepenuhnya di sisi klien.

2. Cadangan Google Drive (opsional)

Jika Anda menautkan Google Drive, file cadangan (puskesdoc_full_backup.json) disimpan di Google Drive milik Anda sendiri, di folder "Akreditasi Puskesmas ILP 2026". Kami tidak memiliki akses ke file tersebut selain melalui izin yang Anda berikan saat login, dan izin itu hanya berlaku untuk file yang dibuat aplikasi ini.

3. API Key Pribadi

API key Gemini / AI yang Anda masukkan tersimpan lokal di browser Anda (dan ikut dalam file cadangan bila Anda mengunduhnya). Jangan membagikan file cadangan kepada pihak yang tidak dipercaya karena berisi kredensial tersebut.

4. Data yang Tidak Kami Kumpulkan

Kami tidak mengoperasikan server analitik, tidak memasang pelacak pihak ketiga, dan tidak menjual atau membagikan data Anda kepada siapa pun.

5. Layanan Pihak Ketiga

Aplikasi menggunakan layanan Google (OAuth login, Google Drive API, model AI Gemini) yang tunduk pada Kebijakan Privasi Google.
